# Claude Code Configuration

This file documents how Claude Code agents should work with this project.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues. Use the `gh` CLI for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles map to GitHub labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo with `CONTEXT.md` at root and `docs/adr/` for architecture decisions. See `docs/agents/domain.md`.
